# Интернет-магазин спортивного питания

Веб-приложение для управления интернет-магазином спортивного питания, построенное на FastAPI с использованием SQLite в качестве базы данных.

## 🚀 Быстрый старт

### Запуск приложения

```bash
uvicorn main:app --reload
```

После запуска приложение будет доступно по адресу: `http://localhost:8000`

### 🔐 Тестовые учетные записи

Для тестирования функциональности администратора доступны следующие учетные записи:

**Учетная запись 1:**
- **Логин:** `admin`
- **Пароль:** `admin0`

**Учетная запись 2:**
- **Логин:** `the_admin`
- **Пароль:** `the_admin`


## 🚀 Функциональность

### 🔐 Аутентификация и авторизация
- Регистрация новых пользователей
- Вход в систему с сессиями
- Ролевая модель (пользователь/администратор)
- Защита маршрутов middleware

### 🛍️ Каталог товаров
- Просмотр товаров с фильтрацией и поиском
- Фильтры по категориям, цене, наличию
- Сортировка по различным параметрам
- Пагинация результатов
- Умные подсказки при поиске

### 👤 Личный кабинет
- Просмотр и редактирование профиля
- История заказов
- Управление адресами доставки

### ⚙️ Административная панель
- Полное управление пользователями
- Управление товарами (CRUD)
- Управление заказами
- Управление адресами
- Управление учетными данными
- Статистика и аналитика

### 📊 Отчеты и аналитика
- Самый крупный заказ с деталями доставки
- Топ покупателей по категориям товаров
- Любимые товары пользователей

## 🛠 Технологический стек

- **Backend**: FastAPI
- **База данных**: SQLite
- **Аутентификация**: Session-based с bcrypt
- **Шаблонизатор**: Jinja2
- **Фронтенд**: HTML/CSS/JavaScript
- **Загрузка файлов**: Поддержка изображений товаров

## 📁 Структура проекта

```
project/
├── main.py                 # Основное приложение FastAPI
├── setting.py             # Настройки приложения
├── DataBase/
│   ├── products.py        # Модели и CRUD для товаров
│   ├── users.py           # Модели и CRUD для пользователей
│   ├── authorization.py   # Аутентификация и авторизация
│   ├── orders.py          # Модели и CRUD для заказов
│   ├── addres.py          # Модели и CRUD для адресов
│   ├── user_order_address.py # Связи пользователей и заказов
│   └── faq.py             # Функции для отчетов и аналитики
├── templates/             # HTML шаблоны
├── static/               # Статические файлы (CSS, JS, изображения)
└── README.md
```

## 🗄 Модели данных

### Основные сущности:
- **Пользователи** - информация о клиентах
- **Товары** - каталог спортивного питания
- **Заказы** - информация о покупках
- **Адреса** - адреса доставки
- **Учетные данные** - логины, пароли и роли
- **Сессии** - активные пользовательские сессии

## 🔧 Установка и настройка

### Предварительные требования
- Python 3.8+
- Установленные зависимости из requirements.txt

### Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd project
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Запустите приложение:
```bash
uvicorn main:app --reload
```

4. Откройте в браузере:
```
http://localhost:8000
```

5. Войдите с тестовыми учетными данными администратора

## 🔧 API Endpoints (есть, но нет прямого доступа)

### Основные маршруты
- `GET /` - Главная страница
- `GET /products` - Каталог товаров
- `GET /profile` - Личный кабинет
- `GET /faq` - Отчеты и аналитика

### Аутентификация
- `GET/POST /login` - Вход в систему
- `POST /logout` - Выход из системы
- `GET/POST /register` - Регистрация

### Административные
- `GET /admin` - Панель администратора
- CRUD операции для всех сущностей

### API endpoints
- `GET /api/search-suggestions` - Подсказки поиска
- `GET /api/popular-searches` - Популярные запросы
- `GET /api/category-lovers` - Топ покупателей по категориям
